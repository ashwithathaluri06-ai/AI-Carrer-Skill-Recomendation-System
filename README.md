# AI Career & Skill Recommendation System

An interactive web application that recommends suitable career paths based on a user's skills and interests.

## Project Overview

The AI Career & Skill Recommendation System analyzes the skills and interests entered by a user and recommends a suitable career path.

The application also provides:

- Career match percentage
- Matching skills
- Recommended skills to learn
- Personalized career guidance
- Multiple career paths

## Features

- User-friendly web interface
- Skill-based career recommendation
- Interest-based career matching
- Career match percentage
- Personalized learning recommendations
- Responsive design
- Multiple career categories

## Career Paths

The system currently supports:

- Data Analyst
- Data Scientist
- AI/ML Engineer
- Software Developer
- Web Developer
- UI/UX Designer
- Cybersecurity Analyst
- Cloud Engineer
- Database Administrator

## Technologies Used

- Python
- Flask
- HTML
- CSS
- Jinja2
