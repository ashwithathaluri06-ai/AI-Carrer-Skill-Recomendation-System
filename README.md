# AI Career & Skill Recommendation System

An interactive web application that recommends suitable career paths based on a user's skills and interests.

## Project Overview

The **AI Career & Skill Recommendation System** helps users identify suitable career paths based on the skills and interests they enter.

The application provides:

* Career match percentage
* Matching skills
* Recommended skills to learn
* Personalized career guidance

## Features

* User-friendly web interface
* Skill-based career recommendations
* Interest-based career matching
* Career match percentage
* Matching skills identification
* Recommended skills for improvement
* Personalized career guidance

## How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/ashwithathaluri06-ai/AI-Carrer-Skill-Recomendation-System.git
```

### 2. Open the project folder

```bash
cd AI-Carrer-Skill-Recomendation-System
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

For Windows:

```bash
venv\Scripts\activate
```

### 5. Install the required packages

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

### 7. Open in your browser

Go to:

```text
http://127.0.0.1:5000
```

## How It Works

1. The user enters their skills and interests.
2. The system analyzes the provided information.
3. The system compares the input with available career paths.
4. A suitable career recommendation is generated.
5. The application displays the career match percentage, matching skills, and recommended skills to learn.
